# 游戏流程图

## 设计说明

### 怪物战力计算规则

**怪物战斗力 = 相邻8个格子的数字之和 ÷ 2**

这个设计的目的：
1. **平衡性**：即使玩家没有完全揭露所有数字，仍然有机会战胜怪物（因为怪物战力是数字总和的一半，相对较低）
2. **策略性**：玩家在倒计时期间，可以主动揭露怪物相邻的格子，在数字格子上部署兵种来增加玩家战力
3. **风险与收益**：玩家需要在倒计时结束前，权衡是否值得消耗回合数去揭露更多格子并部署兵种

### 战斗机制说明

- **怪物战力**：基于相邻8格的所有数字（无论是否已揭示）之和的一半
- **玩家战力**：基于相邻8格中玩家已部署的兵种单位总战力
- **倒计时类型**：回合数倒计时（初始3回合），不是时间倒计时
- **倒计时消耗**：每次点击"结束回合"时，所有激活怪物的倒计时回合-1
- **倒计时期间**：玩家可以继续操作任何格子（没有位置限制）
- **战斗结算**：倒计时归0时，在下次"结束回合"时进行战斗结算

### 卡牌系统

- **发牌机制**：每回合结束时发3张随机卡牌
- **手牌上限**：手牌最大10张
- **部署规则**：卡牌类型必须与数字格子的数字匹配才能部署
- **兵种战力**：兵种战力 = 卡牌类型值（简化设计）

### 回合系统

- **回合流程**：玩家操作 → 点击"结束回合" → 消耗怪物倒计时 → 发新卡牌 → 回合数+1
- **操作类型**：点击格子（揭示）、拖拽卡牌（部署）、结束回合

## 核心游戏流程

```mermaid
flowchart TD
    Start([游戏开始]) --> InitGame[初始化游戏<br/>发3张卡牌]
    InitGame --> GameLoop[进入游戏主循环]
    
    GameLoop --> CheckGameOver{检查游戏结束条件}
    
    CheckGameOver -->|生命值 = 0| GameFail([游戏失败])
    CheckGameOver -->|所有怪物被消灭| GameWin([游戏胜利])
    CheckGameOver -->|游戏继续| PlayerAction[玩家操作]
    
    PlayerAction --> ActionType{操作类型?}
    
    ActionType -->|点击格子| ClickCell[点击空白格子]
    ActionType -->|拖拽卡牌| DeployCard[部署卡牌]
    ActionType -->|结束回合| EndTurn[结束回合]
    
    ClickCell --> CheckCellType{判断格子类型}
    
    CheckCellType -->|怪物格子| TriggerMonster[触发怪物<br/>倒计时3回合]
    CheckCellType -->|数字格子| RevealCell[揭示格子<br/>数字=0自动展开]
    
    TriggerMonster --> CalcMonsterPower[计算怪物战力<br/>相邻8格数字之和 ÷ 2]
    CalcMonsterPower --> PlayerAction
    
    RevealCell --> PlayerAction
    
    DeployCard --> CheckMatch{卡牌类型<br/>匹配数字?}
    CheckMatch -->|是| DeploySuccess[部署成功<br/>卡牌移除]
    CheckMatch -->|否| DeployFail[部署失败]
    
    DeploySuccess --> PlayerAction
    DeployFail --> PlayerAction
    
    EndTurn --> ConsumeCountdown[消耗所有激活怪物<br/>倒计时回合-1]
    ConsumeCountdown --> CheckCountdown{有怪物<br/>倒计时归0?}
    
    CheckCountdown -->|是| BattleSettlement[战斗结算]
    CheckCountdown -->|否| DealCards[发3张新卡牌]
    
    BattleSettlement --> CalcPlayerPower[计算相邻8格<br/>兵种单位总战力]
    CalcPlayerPower --> ComparePower{玩家战力<br/>≥ 怪物战力?}
    
    ComparePower -->|是| PlayerWin[玩家获胜<br/>消灭怪物]
    ComparePower -->|否| PlayerLose[玩家失败<br/>扣除生命值]
    
    PlayerWin --> DealCards
    PlayerLose --> DealCards
    
    DealCards --> TurnPlus[回合数+1]
    TurnPlus --> CheckGameOver
    
    style Start fill:#90EE90
    style GameWin fill:#87CEEB
    style GameFail fill:#FFB6C1
    style TriggerMonster fill:#FFA500
    style BattleSettlement fill:#FF6347
    style PlayerWin fill:#98FB98
    style PlayerLose fill:#FF6B6B
    style DeploySuccess fill:#98FB98
```

## 战斗结算详细流程

```mermaid
flowchart TD
    BattleStart[战斗结算开始] --> GetAdjacentCells[获取相邻8个格子]
    
    GetAdjacentCells --> CalcMonsterPower[计算怪物战力]
    CalcMonsterPower --> GetAdjacentNumbers[获取相邻8格的所有数字]
    GetAdjacentNumbers --> SumNumbers[计算数字之和]
    SumNumbers --> DivideByTwo[数字之和 ÷ 2]
    DivideByTwo --> MonsterPower[怪物战力 = 结果]
    
    GetAdjacentCells --> CalcPlayerPower[计算玩家战力]
    CalcPlayerPower --> FilterDeployedUnits[筛选已部署的兵种单位]
    FilterDeployedUnits --> SumPlayerPower[累加兵种单位战力]
    SumPlayerPower --> PlayerPower[玩家总战力]
    
    MonsterPower --> PowerCompare{玩家总战力 ≥ 怪物战力?}
    PlayerPower --> PowerCompare
    
    PowerCompare -->|是| Victory[战斗胜利]
    PowerCompare -->|否| Defeat[战斗失败]
    
    Victory --> RemoveMonster[移除怪物格子]
    RemoveMonster --> CheckAllMonsters{所有怪物都被消灭?}
    CheckAllMonsters -->|是| TriggerWin[触发胜利条件]
    CheckAllMonsters -->|否| BattleEnd[战斗结束]
    
    Defeat --> ReduceHealth[减少玩家生命值]
    ReduceHealth --> CheckHealth{生命值 ≤ 0?}
    CheckHealth -->|是| TriggerFail[触发失败条件]
    CheckHealth -->|否| BattleEnd
    
    TriggerWin --> BattleEnd
    TriggerFail --> BattleEnd
    
    style Victory fill:#98FB98
    style Defeat fill:#FF6B6B
    style TriggerWin fill:#87CEEB
    style TriggerFail fill:#FFB6C1
```

## 玩家操作流程

```mermaid
flowchart TD
    PlayerAction([玩家操作]) --> ActionType{操作类型?}
    
    ActionType -->|点击格子| ClickCell[点击格子]
    ActionType -->|拖拽卡牌| DragCard[拖拽卡牌]
    ActionType -->|结束回合| EndTurn[结束回合]
    
    ClickCell --> CheckCellState{格子状态?}
    
    CheckCellState -->|未揭示| Reveal[揭示格子]
    CheckCellState -->|已揭示| BlockClick[阻止操作<br/>已揭示的格子]
    
    Reveal --> RevealType{揭示内容类型}
    RevealType -->|怪物格子| TriggerMonster[触发怪物<br/>倒计时3回合]
    RevealType -->|数字格子| CheckNumber{数字值?}
    
    CheckNumber -->|数字=0| AutoExpand[自动展开<br/>相邻空白区域]
    CheckNumber -->|数字>0| ShowNumber[显示数字]
    
    TriggerMonster --> PlayerAction
    AutoExpand --> PlayerAction
    ShowNumber --> PlayerAction
    BlockClick --> PlayerAction
    
    DragCard --> CheckTarget{目标格子?}
    
    CheckTarget -->|已揭示数字格子| CheckMatch{卡牌类型<br/>匹配数字?}
    CheckTarget -->|其他| DeployFail[部署失败]
    
    CheckMatch -->|是| CheckDeployed{格子已有兵种?}
    CheckMatch -->|否| DeployFail
    
    CheckDeployed -->|否| DeploySuccess[部署成功<br/>卡牌移除]
    CheckDeployed -->|是| DeployFail
    
    DeploySuccess --> PlayerAction
    DeployFail --> PlayerAction
    
    EndTurn --> ConsumeCountdown[消耗所有激活怪物<br/>倒计时回合-1]
    ConsumeCountdown --> CheckSettle{有怪物<br/>倒计时归0?}
    
    CheckSettle -->|是| BattleSettle[战斗结算]
    CheckSettle -->|否| DealCards[发3张新卡牌<br/>回合数+1]
    
    BattleSettle --> DealCards
    DealCards --> PlayerAction
    
    style TriggerMonster fill:#FFA500
    style DeploySuccess fill:#98FB98
    style DeployFail fill:#FF6B6B
    style BattleSettle fill:#FF6347
```

## 游戏状态管理

```mermaid
stateDiagram-v2
    [*] --> 初始化
    
    初始化 --> 等待玩家操作: 游戏开始<br/>发3张卡牌
    
    等待玩家操作 --> 点击处理: 玩家点击格子
    等待玩家操作 --> 拖拽卡牌: 玩家拖拽卡牌
    等待玩家操作 --> 结束回合: 点击结束回合
    
    点击处理 --> 怪物触发: 点击到怪物
    点击处理 --> 数字揭示: 点击到数字
    点击处理 --> 等待玩家操作: 无效操作
    
    数字揭示 --> 等待玩家操作: 显示数字<br/>数字=0自动展开
    
    怪物触发 --> 倒计时中: 开始倒计时3回合<br/>计算怪物战力
    倒计时中 --> 倒计时中: 倒计时进行中
    倒计时中 --> 等待玩家操作: 可继续操作任何格子
    
    拖拽卡牌 --> 部署验证: 验证部署条件
    部署验证 --> 等待玩家操作: 部署成功或失败
    
    结束回合 --> 消耗倒计时: 所有激活怪物<br/>倒计时回合-1
    消耗倒计时 --> 检查倒计时: 检查倒计时状态
    
    检查倒计时 --> 战斗结算: 有怪物倒计时归0
    检查倒计时 --> 发牌: 无怪物倒计时归0
    
    战斗结算 --> 战斗胜利: 玩家战力≥怪物战力
    战斗结算 --> 战斗失败: 玩家战力<怪物战力
    
    战斗胜利 --> 发牌: 移除怪物
    战斗失败 --> 检查生命值: 扣除生命值
    
    检查生命值 --> 发牌: 生命值 > 0
    检查生命值 --> 游戏失败: 生命值 = 0
    
    发牌 --> 回合数增加: 发3张新卡牌<br/>回合数+1
    回合数增加 --> 等待玩家操作: 继续游戏
    
    等待玩家操作 --> 检查胜利条件: 每次操作后
    检查胜利条件 --> 等待玩家操作: 还有怪物
    检查胜利条件 --> 游戏胜利: 所有怪物消灭
    
    游戏胜利 --> [*]
    游戏失败 --> [*]
```
