# 魔法军团：地雷战场 (Magic Legion: Minefield Battle)

## 🎮 游戏简介

这是一个基于扫雷玩法的西式奇幻RPG独立游戏。玩家需要在触发怪物（地雷）之前，确保周围有足够的兵种（数字）来击败它们。

## 🏰 游戏机制

### 核心玩法
- **数字格子** = 显示相邻怪物数量（经典扫雷机制），数字0-8
- **怪物格子** = 封印的怪物，点击后触发回合倒计时（3回合）
- **卡牌系统** = 每回合发3张随机卡牌，手牌最大10张
- **回合系统** = 玩家主动点击"结束回合"按钮，消耗怪物倒计时
- **策略要素** = 在倒计时结束前，部署匹配的兵种卡牌来击败怪物

### 职业兵种系统
1. **战士** (类型1，战力1) - 近战肉盾，血量高
2. **弓箭手** (类型2，战力2) - 远程输出，攻击力中等
3. **法师** (类型3，战力3) - 魔法攻击，攻击力高但血量低
4. **圣骑士** (类型4，战力4) - 治疗+防御，全能型职业
5. **盗贼** (类型5，战力5) - 高暴击，闪避能力强
6. **德鲁伊** (类型6，战力6) - 召唤+自然魔法，平衡型
7. **龙骑士** (类型7，战力7) - 飞行单位，全属性优秀
8. **大法师** (类型8，战力8) - 终极魔法，范围攻击

**部署规则**：卡牌类型必须与数字格子的数字匹配才能部署

### 怪物系统
- **怪物战力计算**：相邻8格数字之和 ÷ 2
- **倒计时机制**：点击怪物后开始回合倒计时（初始3回合）
- **倒计时消耗**：每次"结束回合"时，所有激活怪物的倒计时-1
- **战斗结算**：倒计时归0时，对比玩家战力与怪物战力决定胜负
