# 魔法军团：地雷战场 (Magic Legion: Minefield Battle)

## 🎮 游戏简介

这是一个基于扫雷玩法的西式奇幻RPG独立游戏。玩家需要在触发怪物（地雷）之前，确保周围有足够的兵种（数字）来击败它们。

## 🏰 游戏机制

### 核心玩法
- **数字格子** = 职业兵种（战士、法师、弓箭手等）
- **地雷格子** = 封印的怪物（哥布林、兽人、龙等）
- **策略要素** = 在"引爆"怪物前，确保周围有足够的兵种来击败它

### 职业兵种系统
1. **战士** (数字1) - 近战肉盾，血量高
2. **弓箭手** (数字2) - 远程输出，攻击力中等
3. **法师** (数字3) - 魔法攻击，攻击力高但血量低
4. **圣骑士** (数字4) - 治疗+防御，全能型职业
5. **盗贼** (数字5) - 高暴击，闪避能力强
6. **德鲁伊** (数字6) - 召唤+自然魔法，平衡型
7. **龙骑士** (数字7) - 飞行单位，全属性优秀
8. **大法师** (数字8) - 终极魔法，范围攻击

### 怪物系统
- **哥布林** - 需要1-2个兵种击败
- **兽人** - 需要2-3个兵种击败
- **巨魔** - 需要3-4个兵种击败
- **龙** - 需要5-6个兵种击败
- **恶魔领主** - 需要7-8个兵种击败
