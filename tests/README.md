# 单元测试说明

## 测试结构

本测试文件夹与项目解耦，可以独立运行。

## 测试文件

### test_monster_power_distribution.py

测试怪物战力生成函数的分布是否符合预期。

**功能：**
- 测试怪物战力（1-32）的分布
- 统计每个战力值的出现频率
- 计算平均值、中位数、标准差等统计量
- 验证实际分布与理论分布的偏差
- 按区间统计战力分布

**运行方式：**

```bash
# 从项目根目录运行
python tests/test_monster_power_distribution.py
```

**输出说明：**

1. **战力分布统计表**
   - 战力：战力值（1-32）
   - 出现次数：该战力值在采样中出现的次数
   - 实际概率：实际采样得到的概率
   - 理论概率：根据权重表计算的理论概率
   - 权重：该战力值在权重表中的权重
   - 偏差：实际概率与理论概率的差值

2. **统计摘要**
   - 平均值 (Mean)：所有样本的平均战力
   - 中位数 (Median)：中位数战力
   - 25%分位数 (Q25)：25%的样本低于此值
   - 75%分位数 (Q75)：75%的样本低于此值
   - 标准差 (Std Dev)：战力分布的标准差
   - 最小值/最大值：样本中的最小/最大战力

3. **区间分布**
   - 按战力区间统计分布情况

4. **权重验证**
   - 验证权重总和
   - 理论期望值与实际平均值的对比

**预期结果：**

- 平均值应该接近理论期望值（约9.15）
- 平均值应该小于12.0（验证低战力分布）
- 低战力（1-5）应该占约40%左右
- 高战力（26-32）应该占约5%左右

**自定义采样数量：**

可以修改测试文件中的 `sample_size` 参数来改变采样数量（默认10000）。

```python
result = test_monster_power_distribution(sample_size=50000)  # 使用50000个样本
```
