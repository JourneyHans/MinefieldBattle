# 游戏打包说明

## 方法一：使用批处理脚本（Windows推荐）

1. 双击运行 `build.bat`
2. 等待打包完成
3. 打包后的可执行文件位于 `dist\魔法军团地雷战场.exe`

## 方法二：手动打包

### Windows系统

```bash
# 1. 安装PyInstaller（如果还没安装）
pip install pyinstaller

# 2. 打包游戏（使用英文文件名避免编码问题）
pyinstaller --onefile --windowed --name "MinefieldBattle" --hidden-import=pygame --collect-all pygame main.py

# 3. 可选：重命名为中文名称
# move dist\MinefieldBattle.exe dist\魔法军团地雷战场.exe

# 3. 打包完成后，可执行文件在 dist 目录下
```

### Linux/Mac系统

```bash
# 1. 安装PyInstaller（如果还没安装）
pip3 install pyinstaller

# 2. 打包游戏（使用英文文件名避免编码问题）
pyinstaller --onefile --windowed --name "MinefieldBattle" --hidden-import=pygame --collect-all pygame main.py

# 3. 可选：重命名为中文名称
# move dist\MinefieldBattle.exe dist\魔法军团地雷战场.exe

# 3. 打包完成后，可执行文件在 dist 目录下
```

## 打包参数说明

- `--onefile`: 打包成单个可执行文件
- `--windowed`: 不显示控制台窗口（GUI模式）
- `--name`: 指定生成的可执行文件名称
- `--add-data`: 包含数据文件（Python源文件）
- `--hidden-import`: 显式导入可能被遗漏的模块

## 注意事项

1. **首次打包**：第一次打包可能需要较长时间，因为需要收集所有依赖
2. **文件大小**：打包后的exe文件会比较大（通常几十MB），因为包含了Python解释器和所有依赖
3. **杀毒软件**：某些杀毒软件可能会误报，这是正常现象，可以添加信任
4. **字体问题**：如果打包后中文显示异常，可能需要将字体文件一起打包

## 测试打包后的程序

打包完成后，建议：
1. 在 `dist` 目录下找到生成的可执行文件
2. 双击运行测试
3. 如果运行正常，可以将整个 `dist` 目录分发给其他用户

## 分发说明

打包后的程序是独立的，不需要安装Python环境即可运行。只需要：
- Windows: 直接运行 `.exe` 文件
- Linux/Mac: 直接运行生成的可执行文件
