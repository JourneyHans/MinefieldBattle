# 魔法军团：地雷战场 - Demo

## 运行说明

### 环境要求
- Python 3.6+
- Pygame 2.0.0+

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行游戏

```bash
python main.py
```

## 游戏操作

- **左键点击**：揭示格子或部署兵种
  - 点击隐藏的格子：揭示内容（数字或怪物）
  - 点击已揭示的数字格子：部署对应兵种
- **R键**：重新开始游戏

## 游戏规则

1. **数字格子**：显示数字1-8，代表可以部署的兵种类型
2. **怪物格子**：点击后会触发战斗倒计时（5秒）
3. **倒计时期间**：只能操作触发怪物的相邻8个格子
4. **兵种部署**：点击数字格子即可部署对应兵种（战力=数字值）
5. **战斗结算**：
   - 怪物战力 = 相邻8格数字之和 ÷ 2
   - 玩家战力 = 相邻8格已部署兵种总战力
   - 玩家战力 ≥ 怪物战力 → 胜利，怪物被消灭
   - 玩家战力 < 怪物战力 → 失败，扣除1点生命值
6. **胜利条件**：消灭所有怪物
7. **失败条件**：生命值归零

## 游戏界面

- **左侧**：游戏地图（10x10格子）
- **右侧**：游戏信息面板
  - 生命值
  - 回合数
  - 剩余怪物数
  - 倒计时（如果有）

## 颜色说明

- **灰色**：隐藏格子
- **浅蓝色**：已揭示的数字格子
- **绿色**：已部署兵种的格子
- **红色**：怪物格子
- **橙色**：倒计时中的怪物格子
